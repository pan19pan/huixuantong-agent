# 会宣通 Agent

> 会议材料一键成稿 ｜ 安全不外泄 ｜ 公众号宣发更高效

面向全行业公众号运营人员的**会议宣发 AI 助手**：本地处理会议材料，不上云、不外泄，自动整合提炼，一键生成安全合规、重点突出的公众号宣发稿。

👉 **在线体验**：https://USERNAME.github.io/huixuantong-agent/

---

## 这个作品解决什么问题

三类用户每天在做同一件事——把「会议材料」变成「公众号宣发稿」：

- 民营企业 / 集团公司：公众号运营、品牌宣传、行政文秘
- 事业单位 / 国企 / 机关单位：宣传岗、文稿整理人员

但他们卡在三个地方：

| 痛点 | 具体表现 |
| --- | --- |
| 材料多、杂、散 | 发言稿、纪要、笔记、图片分散各处，无法逐字逐句读完，摘抄整合耗时巨大 |
| 不敢用外部 AI | 企业怕商业秘密泄露，政企怕工作秘密与敏感信息外流，外部 AI 工具是保密红线 |
| 纪要不能直接发 | 公众号需要抓会议精神、抓传播亮点，普通纪要只是信息堆砌 |

产品定位：**只做材料整理 + 风险提示 + 宣发初稿生成**，不替代人工审核、保密审查与三审三校。

## 在线演示覆盖的完整流程

点击「交互演示」标签，可完整跑通一次真实业务场景（虚构案例：某科技公司 2026 年四季度经营工作会议，4 份会议材料 → 1 篇公众号稿件）：

1. **上传会议材料** —— 发言稿 / 纪要 / 板书照片 / 速记笔记，全部本地处理
2. **AI 本地解析提炼** —— 多源整合，提取会议主题、核心决策、重点工作、会议精神、宣发重点
3. **敏感内容提示** —— 自动标记商业秘密、内部数据、内部讨论，标黄提示「建议人工复核」
4. **人工确认素材池** —— 逐条勾选保留 / 剔除 / 编辑原文，只有人工确认的内容才进入生成环节
5. **一键生成宣发稿** —— 公众号标题、导语、正文段落，真实排版预览
6. **溯源与合规留痕** —— 每段可回溯原始材料，全部操作写入日志

## 核心设计：为什么它「敢用」

参数再好的 AI 工具，在政企场景也过不了保密这一关。这个产品的设计重心不在生成能力，而在**如何让人放心地信任 AI 的输出**。

### 1. 三层隔离机制
```
原始材料 → 人工筛选 → 可宣发素材池 → 生成模块
```
生成模块**只能读取人工确认后的内容**，从架构上禁止模型私取未放行片段。高风险内容进入隔离区后不可被调用、不可生成、不可用于替换。

### 2. AI 只提示，不决策
不自动判定「可发 / 不可发」，只输出风险标签。**风险标签永久跟随对应生成段落**——即使该片段被人工放行进入素材池，复审时标签依然可见，不会在生成环节消失。

### 3. 悬浮即时溯源（核心交互）
鼠标悬浮在稿件的**任意 AI 生成段落**上，自动弹出悬浮来源面板，无需跳转页面：
- 展示对应的原始素材池原文（音频素材可回放时间轴片段）
- 展示该片段的历史 AI 风险标记记录
- 用户 hover 即可对照「AI 改写结果 VS 原始素材」，快速发现模型为了行文通顺而篡改原意的问题

### 4. 一键替换回原文
在悬浮面板内直接点击「一键替换为原始文本」，把当前段落还原为未经润色的素材池原文。
- 替换动作完整写入操作日志：时间、替换前 AI 文本、替换后原始文本、素材来源
- 仅可调用**已进入素材池**的内容，高风险隔离片段不允许被调用

### 5. 事实与润色分层
- **事实层**：全部来源于人工确认素材池，绑定来源与风险标记，不可随意篡改
- **润色层**：仅优化句式、排版、传播表达，不新增业务事实

### 6. 全程溯源留痕
所有确认、编辑、生成、替换操作均记录在案，不可篡改，满足民企合规、政企三审三校、审计备查要求。

## 衡量产品价值

| 维度 | 指标 |
| --- | --- |
| 效率 | 材料整理时间减少 80%+；出稿速度提升 70%+ |
| 安全 | 数据不上云；敏感内容提示覆盖率高；有效降低泄密风险 |
| 宣发质量 | 会议精神抓取准确、重点突出、结构符合传播逻辑、稿件可直接使用率高 |

**识别「内容看似通顺但不能发布」的信号**：包含未公开内部策略、包含敏感数据或未官宣信息、包含内部讨论、内容偏离会议原意、过度扩展脑补——AI 自动提示，由人最终判断。
